# Página Pessoal - Programação WEB
Este repositório reúne o código do meu portfólio pessoal, desenvolvido como prática de HTML e CSS para apresentação da disciplina. A estrutura foi pensada para destacar informações pessoais, projetos e habilidades de forma clara e visualmente atrativa. O site foi publicado no GitHub Pages, permitindo fácil acesso e visualização online em qualquer momento.
